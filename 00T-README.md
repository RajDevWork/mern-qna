# TypeScript Complete Guide (Production Edition)

This guide set covers TypeScript in depth and shows how to use it in production-grade **Node.js**, **React**, and **Next.js** projects, including every important command.

## Files in this guide

| File | Contents |
|---|---|
| `01T-typescript-fundamentals.md` | Core language, types, tsconfig, compiler commands |
| `02T-typescript-node.md` | Node.js + TypeScript production setup, tooling, commands |
| `03T-typescript-react.md` | React + TypeScript (Vite), component/hook typing, build commands |
| `04T-typescript-nextjs.md` | Next.js + TypeScript, App Router, API routes, deployment commands |
| `05T-tooling-cheatsheet.md` | ESLint, Prettier, testing, CI/CD, Docker, monorepo commands |

Read them in order, or jump to whichever stack you need.
