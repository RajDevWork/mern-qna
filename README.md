## 📖 How to Use This Guide

- **First pass:** Read a file top to bottom, don't skip the Hinglish explanation — it's there to help the concept stick before you memorize the English interview answer.
- **Revision pass:** Just read the bold **"Interview Answer"** blocks and code snippets — skip the Hinglish once you know the concept.
- **Night before interview:** Use the ✅ checklist below — tick off topics as you revise them.
- Files with **no answers** (Real-World, Scenario-Based) are practice lists — talk through your own answer out loud or write one line per question.

## 🎯 Suggested Study Order for MERN Roles

If you're specifically targeting **MERN stack** roles (not PHP/Laravel), focus on files **1–14** in this order, since it mirrors how interviews usually flow — fundamentals → language → framework → backend → database → system design:

1. JavaScript (06) — everything else depends on this
2. React (07) — biggest weight in most MERN interviews
3. Node + Express (08)
4. MongoDB (09)
5. HTML (01) + CSS (02) — quick refresh, usually only a few questions asked
6. Browser & Rendering (03) + Performance (05)
7. Frontend Security (04)
8. Tricky Frontend (13) — do this once you're comfortable with JS/React, these are gotcha questions
9. System Design & DevOps (10) + Real-World (11) + Scenario-Based (12) — for mid/senior roles
10. Database fundamentals (14)

Skip file 15 (PHP + Laravel) entirely unless the role specifically mentions it.
